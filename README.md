# STM32-FLIGHT-CONTROLLER
Open-source STM32F405 flight controller designed in EasyEDA Pro. 6-layer PCB with ICM-42688-P IMU, DPS368 barometer, 16MB W25Q128 blackbox flash, MP9943 buck regulator, USB-C and JST-SH connectors for ESC and peripherals. Includes schematic, BOM, Gerbers and pick-and-place files ready for JLCPCB assembly.
